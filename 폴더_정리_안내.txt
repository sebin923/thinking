생각한줄 파일 정리 — 2026년 11월 26일

업로드 범위
백엔드의 개인화 주제 추천, 피드백·채점 결과 검증, 별도 자료 사실검사 연결 코드와 테스트를 관리합니다.
Tailscale로 GPU 서버를 호출하는 HTTP 연결 코드는 EC2 백엔드에 남깁니다.

프론트 보존
팀원이 Git master에 올린 프론트, 단원 설명과 O/X 문제는 이번 변경에서 수정하지 않습니다.
최신 master의 문법 퀴즈 난이도 처리와 DB O/X 조회 기능도 유지합니다.

GPU PC 보관
LLM 서버·학습 코드·가중치·학습/수집 자료, PC용 GPU 실행 도구와 발표 자료는 업로드에서 제외합니다.
이미 Git에 등록된 GPU 코드·수집 자료와 개인 IDE 설정은 이번 커밋에서 추적을 정리합니다.
원래 GPU PC 작업 폴더의 파일은 삭제하거나 옮기지 않습니다.

개인 설정 보관
실제 .env, 토큰, 개인키, 로컬 DB, 가상환경과 설치 패키지는 Git에 넣지 않습니다.
빈 환경설정 견본과 EC2 연결·확인 안내는 공유합니다.

적용 구분
Git 업로드와 EC2 적용은 별개입니다. 이번 작업에서는 EC2/RDS 변경이나 GPU 재시작을 실행하지 않습니다.
자세한 연결 조건과 검사 방법은 deploy/README_EC2_GPU.ko.md에 정리합니다.
